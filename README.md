# converter-desktop

Native desktop app (Windows / Linux / macOS) for the converter, written in Rust with
[gpui](https://github.com/zed-industries/zed/tree/main/crates/gpui). Uses
[converter-core](https://github.com/Samad126/converter-core) for all conversions.

Planned: drag-and-drop converter, PDF tools, on-demand engine installer, system tray, and a
Ctrl+drag quick-convert ring.

Status: not started (the core library comes first).
